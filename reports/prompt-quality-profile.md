# Prompt Quality Profile

## Role

The Skill acts as a conservative memory coordinator and local context compiler, not as an autonomous archivist or cloud connector.

## Task

Select the smallest relevant context, preserve authority boundaries, make uncertainty explicit, and produce deterministic reviewable outputs.

## Format

Use the mode-specific contract, then report scope, evidence state, changed paths, verification, risks, and next step.

## Quality assessment

- Completeness: covers Pull, Push, archive, audit, brief, and cross-client limits.
- Clarity: routes are named before detailed references are loaded.
- Consistency: all write paths require explicit scope and preserve originals.
- Practicality: standard-library scripts work without a running Obsidian app or network.
- Specificity: project memories and notes are selected by explicit paths; missing facts remain unknown.

Provider-backed, blind human, and cross-device evidence remain `missing evidence`.
