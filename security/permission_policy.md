# Permission Policy

The package has one approved capability: `file_write`.

It is limited to the selected Vault target, an explicitly selected context-brief output directory, and the package worktree during development. Archive sources are read-only. The package has no network mutation, cloud upload, browser, chat-cache, credential, or private-key permission.

The approval is tied to the current local maintenance request and expires on 2027-09-18. A future client or deployment must re-review the scope before adding a new capability.
